
# IncuBrix PS3 — Project Report

## 1. Project Overview

**Project name:** Script-to-B-roll Video Engine  
**Problem statement:** PS3

The project aims to accept a text script, generate a voiceover, create a scene timeline and captions, and produce a video output.

## 2. Implemented Features

- FastAPI backend with API documentation.
- Script submission through the job creation endpoint.
- MP3 voiceover generation and download.
- Scene timeline saved as JSON.
- Captions saved as SRT.
- MP4 video output generated by the current prototype.

## 3. Testing and Evidence

The following files were found in the local project folder during verification:

- `app.py`
- `README.md`
- `requirements.txt`
- Generated MP3 voiceover files.
- Generated timeline JSON files.
- Generated SRT caption files.
- An MP4 video output.

The job creation endpoint returned HTTP 202 and the status `voiceover_ready` during testing. The generated MP3 was downloaded successfully.

## 4. Limitations

- Full automatic selection and integration of relevant real-world B-roll footage is not yet confirmed as implemented.
- The current MP4 output must be reviewed to confirm its visual content and synchronization.
- A publicly accessible live demo has not yet been verified.
- Additional testing and integration remain necessary.

## 5. Conclusion

The current implementation is a partial prototype demonstrating script submission and voiceover generation, with timeline, caption, and video output files present. Further work is required to complete and validate the full B-roll video-generation workflow.
