
# Sources and Dependencies

## 1. Python Dependencies

The project uses Python packages for the API and supporting functionality.

- FastAPI — API framework.
- Uvicorn — ASGI server.
- Additional dependencies are listed in `requirements.txt`.

## 2. API Documentation

- FastAPI interactive documentation: `/docs` on the running development server.
- OpenAPI specification: `openapi.yaml`.

## 3. Generated Project Outputs

The following outputs were generated during local testing:

- MP3 voiceover files.
- JSON scene timeline files.
- SRT caption files.
- MP4 video output.
